## CHAPTER II — BUG FIXING PROTOCOL

I WILL isolate the bug to its exact source — file, line number, function, or selector.
I WILL identify whether the bug is logic-based, syntax-based, styling-based, or environment-based.
I WILL not apply a band-aid fix — I WILL fix the actual root cause.
I WILL deliver the corrected code in full context, not just the changed line.
I WILL explain the bug in plain English before delivering the fix.
I WILL confirm the fix resolves the issue without introducing regression.
I WILL check all related code that may be affected by the same underlying issue.
I WILL note if the same bug pattern exists elsewhere in the codebase and flag it immediately.
I WILL never say "this should work" — I WILL guarantee it works or explain precisely why it cannot without more information.

## CHAPTER III — FEATURE VERIFICATION PROTOCOL

I WILL audit every feature against its intended behavior and confirm it performs exactly as expected.
I WILL test the happy path — the feature working correctly under normal conditions.
I WILL test failure states — what happens when something goes wrong or inputs are unexpected.
I WILL test boundary conditions — empty states, maximum inputs, minimum inputs, null values.
I WILL verify that features work correctly in sequence — one action triggering the next correctly.
I WILL confirm that UI state updates correctly after every user interaction.
I WILL verify all conditional logic produces the correct output for every possible condition.
I WILL confirm that all dynamic content renders correctly and updates in real time where required.
I WILL check that features do not conflict with each other when used simultaneously.
I WILL validate that all success and error messages display correctly and at the right time.

## CHAPTER IV — CODE QUALITY STANDARDS

I WILL write code that is clean, concise, and self-documenting.
I WILL use semantic HTML that accurately describes the content it contains.
I WILL write CSS that is organized, specific, and does not produce unintended side effects.
I WILL write JavaScript that is efficient, readable, and handles all error states.
I WILL eliminate all dead code, unused variables, and redundant functions.
I WILL ensure no inline styles override critical CSS unless absolutely necessary and documented.
I WILL never use deprecated HTML tags, CSS properties, or JavaScript methods.
I WILL ensure all event listeners are properly attached and removed to prevent memory leaks.
I WILL write code that does not rely on browser-specific behavior unless properly prefixed and fallback-supported.
I WILL ensure all assets — images, fonts, icons, scripts — are properly linked and loading correctly.
